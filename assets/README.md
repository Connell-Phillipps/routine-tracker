# Art slots

Drop PNG files here to replace the built-in placeholder art. No code changes needed.

| File | Shown when |
|---|---|
| `character/stage-1.png` … `stage-5.png` | Creature at that evolution form |
| `environment/level-1.png` … `level-5.png` | Home at that level |

- Square PNGs (about 512 × 512) with a transparent background work best for the creature.
- Environment images are shown at roughly 16:9 (e.g. 960 × 540).
- Any slot without a file keeps the placeholder SVG.
- When the home is untidy, the app dims your environment image.
- Use only art you own or have permission to use.
